# IAIN Curup AI Assistant

AI chatbot berbasis Gemini AI untuk layanan kampus.

## Features

- AI Chatbot
- MongoDB Memory
- Real-time Typing
- Markdown Rendering
- Syntax Highlight
- Multi Conversation

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Gemini AI
- Vanilla JavaScript

## Installation

```bash
npm install
node index.js
```
